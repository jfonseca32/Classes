# CS 3630 Project 1 — Python and Webots Foundations

## Project structure — 100 points total

Project 1 has **two distinct components** and **two separate Gradescope
submissions**:

| Component | Purpose | Gradescope submission | Points |
|---|---|---|---:|
| [Project 1A — Python Fundamentals](project_1a_python/PROJECT_1A_PYTHON_INSTRUCTIONS.md) | Learn and practice the Python used in later projects | `project1.py` only | 50 |
| [Project 1B — Webots Installation Check](project_1b_webots/PROJECT_1B_WEBOTS_SETUP_INSTRUCTIONS.md) | Install Webots and verify its Python controller works | One PNG, JPG, JPEG, or PDF screenshot | 50 |
| | **Project 1 total** | **Two submissions** | **100** |

The two components are graded separately on Gradescope. Uploading Project 1A
does not submit Project 1B, and vice versa.

## Recommended order

1. Begin [Project 1A](project_1a_python/PROJECT_1A_PYTHON_INSTRUCTIONS.md): set up the shared `cs3630_p1`
   Conda environment following its instructions, then work through its
   notebook in order.
2. Install and verify Webots using the
   [Project 1B instructions](project_1b_webots/PROJECT_1B_WEBOTS_SETUP_INSTRUCTIONS.md). Start early in case
   your operating system, permissions, or graphics driver needs attention.
3. Return to Project 1A and finish its tests.
4. Check that you made both Gradescope submissions.

## Submission checklist

### Project 1A — 50 points

- The `cs3630_p1` Python 3.12 environment is set up and used for the notebook and
  tests (see the Project 1A instructions).
- `project1.py` contains implementations for all TODOs.
- `student_info()` in `project1.py` contains your full name and GT username.
- `project1.ipynb` is an instructional tutorial and is not submitted.
- Public tests pass locally.
- Only `project1.py` is uploaded to the **Project 1A** Gradescope assignment.

### Project 1B — 50 points

- The `cs3630_p1` environment from Project 1A exists with its dependencies
  installed.
- Webots is installed and uses the Python path from the `cs3630_p1`
  environment.
- The provided verification world runs: the green setup robot moves and the
  simulation time advances.
- The console shows `CS 3630 WEBOTS SETUP SUCCESS`.
- One readable screenshot is uploaded directly to the **Project 1B** Gradescope
  assignment. Do not use a notebook or PowerPoint for this screenshot.

Deadlines and any required Webots version will be announced in the course
schedule or on the course communication platform.
